# 3SE-RF26Detection-model-refining
基于3SE中d开头的模拟器和深大26开源版识别模型的数据标注训练手册：
注意：此项目用openvino和intel显卡，cuda需要让ai做迁移
文件夹：
1.runedetectionmodel
其中是深大的识别模型和识别程序，里面含有初始的onnx模型，不是手册重点
2.runefinetune
用于对模型的微调，内含有数据标签
内部tools里面含有手动标注的html程序
3.tools
里面是一些工具，包括
1.从模拟器导出帧
2.手动设置能量机关的模式
具体命令行详见tool中的declaration.txt
一个完整的训练流程：
tools里面找工具实现数据集的采集，再在runefinetune里面利用虚拟环境训练
已跑通流程，效果未确认。
迁移该项目需要注意：
1.绝对路径改成自己电脑的
2.本仓库不包含模拟器,应先启动模拟器手动对准能量机关
3.训练效果不保证，实车可能还是用原来的权重
26.10.12/19：00更新说明：
修复训练不收敛的问题，原因是原来一个图中标注多个对象，共用一个心，后面的对象会覆盖前面的，导致信息丢失，而评估 的时候用的是原来的多对象，误差会变很大，平均30+px，新训练时目测收敛。还未验证精度.
